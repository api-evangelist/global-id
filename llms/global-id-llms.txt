# GlobaliD

> GlobaliD is a decentralized digital-identity platform. It lets people create a portable, self-sovereign identity and lets developers add "Sign in with GlobaliD", issue verifiable credentials, and verify identity claims (e.g. age 18+) through issuer/verifier toolkits built on Hyperledger Aries. Access to the developer portal is invitation-based. Surfaced in the API Evangelist network as a portfolio company of 500 Global.

## Authentication
- OAuth2. "Sign in with GlobaliD" uses the authorization-code flow (globalid-connect-sdk). Server-side issuer/verifier toolkits authenticate with a developer-app client ID + client secret (Ory Hydra authorization server).
- Auth profile: authentication/global-id-authentication.yml
